# Supplied DAR brand assets

Source: supplied DAR visual identity HTML (`2 FINAL VISUAL IDENTITY HTML.html`).

Service icons are the original SVG geometry from the source, with only fixed colour replaced by currentColor and width/height normalized to 24. All retain the original 24 × 24 viewBox. Use inline or as CSS masks to inherit colour; external img use defaults to black.

icon-construction.svg is an exact alias of the source CRANE icon. There is no separately named CONSTRUCTION icon.

The source logo symbol uses CSS geometry, not SVG paths. icon-symbol.svg transcribes its standalone variant exactly: circle outer diameter 22, border 3, top 4, gap 8, line 5 × 88. The 35 × 88 viewBox removes only surrounding layout space. Orange and white variants preserve the same geometry.

No supplied /public/brand files were changed.
